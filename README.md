An open passport spread of the Republic of Tavora, a tidal island republic: a bilingual data page with a photorealistic portrait of holder Maren Ilse Voss and a fully check-digit-valid ICAO machine-readable zone faces a visas page of ferry, causeway and airport stamps — including a Bresk visa valid only within posted low-tide windows. The spread is generated deterministically by `draw.py` (Python + Pillow) from `portrait.png`.

## Run it

```sh
python3 main.py
```
